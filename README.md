# 🪐 Claro Órion — CRM & Sistema Inteligente de Vendas

Sistema web completo de **CRM, Simulação de Ofertas, Quebra de Objeções e Esteira Pós-Venda**, projetado para consultores de telecomunicações de alta performance.

> **Nota de Portfólio:** Esta versão pública opera em **Modo Demonstração** com clientes, telefones, agendamentos de instalação e históricos 100% fictícios.

---

## ✨ Funcionalidades Principais

- **👥 Carteira Inteligente de Clientes (Lista & Kanban):** Gestão de leads com filtros de Fila de Ataque, Clientes Ouro, alerta de negociação esfriando e chip de vencimento de fidelidade.
- **🧮 Simulador de Propostas Comparativo:** Cálculo automático de Combos (Móvel + Fibra + TV + À La Carte + Dependentes) com comparação lado a lado (Opção 1 vs Opção 2) e custo diário.
- **💬 Gerador de Copy & Disparo WhatsApp:** Templates persuasivos com preenchimento automático de variáveis do cliente e abertura direta no WhatsApp.
- **🛡️ Central de Quebra de Objeções:** Scripts rápidos categorizados para contornar objeções de preço, multa de fidelidade, cobertura e decisão.
- **🔧 Esteira de Instalações & Comissões (24h úteis):** Acompanhamento pós-venda em 3 etapas (*Aguardando Instalação → Instalado → Comissionado*) com cronômetro automático de auditoria.
- **📈 Relatórios Mensais & Checklist Diário:** Métricas de conversão, receita contratada e rotina operacional do consultor.

---

## 🛠️ Stack Tecnológica

- **Frontend:** React 18, Tailwind CSS, Lucide Icons
- **Bundler:** esbuild (build ultrarrápido)
- **Persistência Demo:** LocalStorage isolado + Serverless API Mock
